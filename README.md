# 📈 Stock Forecasting App

An interactive stock forecasting application built using **Python, Streamlit, yFinance, Prophet, Pandas, and Plotly**.

### Features

* Fetches historical stock data using yFinance.
* Displays historical Open and Close prices.
* Uses **Prophet** for time-series forecasting.
* Allows users to select a forecast period from **1 to 5 years**.
* Provides interactive stock and forecast visualizations using Plotly.
* Displays Prophet forecast components.

### Tech Stack

**Python | Pandas | yFinance | Prophet | Plotly | Streamlit**

### How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

> **Note:** This is an academic/learning project. The forecasts are for demonstration purposes and should not be considered financial advice.
